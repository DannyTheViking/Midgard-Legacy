# Update 024 installation

1. Run migrations through 023 if they have not already been installed.
2. Run `supabase/migrations/024_complete_recipes_royal_tools_and_repairs.sql` in Supabase SQL Editor.
3. Replace the site files with this project folder.
4. Sign out, sign back in and hard-refresh the browser.

This update makes the complete current Workbench recipe list visible. Recipes above the station level remain visible but locked.
The King now grants a permanent Iron Axe and Iron Pickaxe at 100/100 durability when the tutorial is completed.
Permanent profession equipment can be repaired from its Gathering equipment card.
