# Crafting maths audit

All stock boxes now display the quantity of finished items,
not the number of recipe batches.

Examples:

- 232 Iron Bars -> 5,800 Iron Nails
- 232 Iron Bars -> 464 Iron Hoops
- 232 Iron Bars -> 116 Iron Axe Heads
- 327 Birch Logs -> 654 Birch Planks
- 204 Oak Logs -> 408 Oak Planks

Recipes with multiple ingredients display every ingredient
that limits the maximum quantity.
