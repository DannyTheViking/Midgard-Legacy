# Update 031 — Warrior Tasks and Resource Repairs

## Database

Already installed directly in Supabase. The included SQL is retained for project history.

## Warrior Tasks

- 1,008 possible Daily task variants.
- 1,008 possible Weekly task variants.
- 1,008 possible Monthly task variants.
- Ten tasks are selected for each period.
- Recent tasks are avoided for 90 days where possible.
- Tasks are filtered against currently usable systems.
- Rewards: Daily 1,000 Silver; Weekly 10,000 Silver; Monthly 100,000 Silver.

## Tool Repairs

- Repairs unlock after completing the first job for Bjørn the Blacksmith.
- Repair Tool replaces Repair Axe.
- A tool dropdown appears when more than one profession tool is owned.
- A repair-material dropdown allows sensible resource choices.
- Repairs no longer spend Silver.
- The Training Grounds remains the intended Silver sink.
